# PocketCode Desktop (Windows / Linux)

Полноценный компаньон Android-приложения на стандартной Python 3: тот же набор
возможностей — чат с очередью, проекты и файлы, агенты, навыки, локальные модели,
провайдеры, настройки эко-режима и **двусторонняя синхронизация** с телефоном.
Интерфейс — тема «Аврора» с боковой навигацией, как в приложении.

Это не урезанный «мост» и не порт Compose 1:1: логика та же, а визуальные
компоненты переписаны на HTML/CSS под браузер.

## Запуск

```sh
python3 pocketcode_desktop.py
# открой http://127.0.0.1:8765/
```

Параметры: `--port 8765`, `--host 127.0.0.1`, `--no-browser`. Чтобы телефон в той же
Wi-Fi сети отправлял события, запусти с `--host 0.0.0.0` и задай токен.

## Разделы

- **Чат** — сообщения, копирование и время, очередь («В очередь» / «Очередь»), компактный режим.
- **Проекты и файлы** — создание проектов, просмотр и редактирование текстовых файлов; изменения идут в очередь синхронизации.
- **Агенты** — список агентов с включением/выключением и роли моделей (планирование/выполнение).
- **Навыки** — включение/выключение, свёрнутый список при >20, кнопки наверх/вниз, создание своих навыков.
- **Локальные модели** — адрес OpenAI-совместимого сервера; «Использовать» делает модель активной сразу.
- **Провайдеры** — несколько профилей, выбор активного, ключ не показывается в списке.
- **Синхронизация** — адрес телефона, токен, E2E-пароль, интервал, проверка связи, импорт/экспорт.
- **Настройки** — «Меньше запросов» и «Эко-режим» для экономии токенов.

## Синхронизация

Протокол v2, двусторонний: подробности в [sync_protocol.md](sync_protocol.md).
ПК принимает пакеты телефона и сам отправляет события на телефон, с ретраями и
дедупликацией по `(seq, device)`. Секреты маскируются в логах. E2E — AES-256-GCM,
совместимый с `SyncCrypto` в Android (нужен пакет `cryptography`).

## Тесты

```sh
python3 -m unittest discover -s desktop -p 'test_*.py'
```

Проверяются безопасные пути, маскировка секретов, дедупликация, full-пакет,
шифрование и активные навыки/агенты. Зависимостей нет, кроме опциональной
`cryptography` для E2E.
