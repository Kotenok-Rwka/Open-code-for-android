# PocketCode Desktop (Windows / Linux)

Компаньон Android-приложения на стандартной Python 3: та же логика и те же разделы,
что на телефоне, но интерфейс переписан на HTML/CSS под компьютер. Тема — **«Аврора»**:
холодный фон, бирюзово-синие акценты, стеклянные карточки, боковая навигация с
группами «Чат · Проект · Агент · Ещё», как в приложении.

## Запуск

```sh
python3 pocketcode_desktop.py
# открой http://127.0.0.1:8765/
```

Параметры: `--port 8765`, `--host 127.0.0.1`, `--no-browser`. Чтобы телефон в той же
Wi-Fi сети отправлял события, запусти с `--host 0.0.0.0` и задай токен.

Зависимостей нет, кроме стандартной библиотеки. Для E2E-синхронизации нужен
опциональный пакет `cryptography` (в готовых сборках он уже включён).

## Что умеет

- **Чат с агентом** — модель вызывает инструменты `list_files`, `read_file`,
  `write_file`, `edit_file`, `grep`, `bash`, `use_skill`, `update_plan`. Лента
  показывает шаги, вывод команд и правки; «Стоп» останавливает задачу. Опасные
  команды (`rm -rf`, `sudo`, перезапись диска) требуют подтверждения.
- **Сессии** — несколько чатов с историей, переименование, удаление, свой проект у чата.
- **Проекты и файлы** — свои папки и подключение существующих, редактор, создание и
  удаление файлов, поиск по тексту, дерево размеров.
- **Правки и откат** — перед каждой задачей снимается снимок проекта; видно, какие
  файлы добавлены, изменены или удалены, и можно вернуть снимок целиком.
- **Git и GitHub** — статус, коммиты, diff, ветки, коммит, переключение ветки,
  клонирование репозитория.
- **Терминал** — команды в папке проекта с кодом возврата.
- **Модели и ключи** — несколько OpenAI-совместимых профилей (OpenAI, OpenRouter,
  Groq, Gemini, DeepSeek, свои адреса), маскировка ключей в интерфейсе.
- **Локальные модели** — каталог GGUF с Hugging Face, скачивание с прогрессом и
  **отменой**, удаление, выбор модели, запуск `llama-server` (llama.cpp) и
  подключение LM Studio/Ollama.
- **Навыки** — встроенные навыки про современные сайты, интерфейсы, темы приложений,
  дашборды, мобильный UI, доступность, производительность и правки без регрессий;
  свои навыки; включение и выключение.
- **Плагины с GitHub** — поиск по названию, описанию и README. Русский запрос
  переводится на английский, описания — обратно. Выдача постраничная по 40
  результатов, кнопка «Показать ещё». Любой репозиторий добавляется как навык.
- **Агенты и роли моделей** — сохранённые агенты с целями, роли планирования и выполнения.
- **Контекст** — сколько сообщений, символов и токенов уходит модели и что в системном промпте.
- **Сравнение моделей** — один запрос в несколько профилей одновременно.
- **Экономия токенов** — режимы «Меньше запросов» и «Эко», лимит истории, обрезка
  вывода инструментов, кеш повторных вызовов, навыки в промпте только названиями.
- **Оформление** — 6 акцентов, компактная плотность, размер шрифта, фон, анимации.
- **Синхронизация** — протокол v2, двусторонний, E2E AES-256-GCM.
- **Служебное** — диагностика, проверка обновлений GitHub, резервная копия и импорт,
  расход токенов, очередь задач, история чатов.

## Синхронизация

Протокол v2, двусторонний: подробности в [sync_protocol.md](sync_protocol.md).
ПК принимает пакеты телефона и сам отправляет события на телефон, с ретраями и
дедупликацией по `(seq, device)`. Секреты маскируются в логах.

## Тесты

```sh
python3 -m unittest discover -s desktop -p 'test_*.py'
```

Проверяются безопасные пути, маскировка секретов, дедупликация, full-пакет,
шифрование, активные навыки/агенты, перевод запроса GitHub и ограничение истории.
