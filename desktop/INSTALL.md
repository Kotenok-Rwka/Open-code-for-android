# PocketCode Desktop — установка (Windows / Linux)

Нативное приложение, браузер не нужен: свой интерфейс в теме «Аврора» с боковой
навигацией «Чат · Проект · Агент · Ещё». Внутри тот же агент и инструменты, что в
Android-приложении: проекты и файлы, снимки и откат, git, терминал, провайдеры и
ключи, локальные модели со скачиванием и отменой, навыки и плагины с GitHub,
экономия токенов и двусторонняя синхронизация с телефоном и другими устройствами.

Для E2E-шифрования синхронизации используется пакет `cryptography` (в готовых
сборках он уже включён). Без пароля шифрование не требуется.

## Windows 10/11 (portable EXE)

1. Готовый вариант: распакуй `PocketCodeDesktop-<версия>-windows.zip`, запусти
   `PocketCodeDesktop.exe` — откроется своё окно приложения, консоли и браузера нет.
   Если Windows SmartScreen ругается — «Подробнее → Выполнить в любом случае».
2. Для сборки самому: Python 3.10+ с https://python.org (Tkinter уже внутри), затем
   `powershell -ExecutionPolicy Bypass -File build_windows.ps1`.
3. Из исходников без сборки: `python pocketcode_app.py`.

## Linux (Debian/Ubuntu, .deb)

```sh
sudo apt install ./pocketcode-desktop_<версия>_amd64.deb
pocketcode-desktop
```

Пакет сам ставит зависимость `python3-tk` (Tkinter). Или без пакета:

```sh
sudo apt install python3-tk
python3 desktop/pocketcode_app.py
```

## Продолжить работу с любого устройства

1. На ПК раздел «Синхронизация» → включи, укажи адрес телефона, токен и пароль →
   «Сохранить» → «Проверить связь».
2. Токен ПК для телефона показывает кнопка «Показать токен для телефона».
3. На телефоне: меню «⋮» → «Автосинхронизация» → `http://<IP ПК>:8765` и тот же токен.
   На ПК слушает адрес `0.0.0.0` по умолчанию, так что телефон в той же Wi-Fi сети
   подключится сразу. Если синхронизация не нужна — запусти с `--host 127.0.0.1`.
4. Телефон присылает сообщения и файлы на ПК, ПК отправляет свои изменения. Лента чата
   обновляется сама; кнопка «Проверить обновления с устройств» перечитывает историю.
5. Второй ПК или другое устройство подключается так же — в поле «Адрес телефона/устройства».

Расшифровка пакетов — в `sync_protocol.md` (v2). Секреты маскируются до отправки.

## Ручной импорт/экспорт

- «Резервная копия» → «Экспорт в JSON» / «Импорт из JSON».
- На телефоне: «Экспорт истории на ПК» / «Загрузить с ПК» в меню «⋮».

## IDE

См. `EDITOR_INTEGRATION.md`. Мост: `python3 ide_bridge.py`, порт 8766.

## Синхронизация через интернет (мобильный интернет, другой город)

1. На ПК запусти приложение: `python3 desktop/pocketcode_app.py`.
2. Сделай ПК доступным извне, например Cloudflare Tunnel:
   ```sh
   cloudflared tunnel --url http://localhost:8765
   ```
   Он даст адрес вида `https://xxx.trycloudflare.com`.
3. На телефоне: «Автосинхронизация» → вставь этот HTTPS-адрес и токен ПК, выключи
   «Только Wi-Fi», нажми «Проверить подключение».

## Безопасность

Слушай только `127.0.0.1`, если синхронизация не нужна. Для удалённого доступа
обязательно используй HTTPS-туннель и токен: без токена приложение отклоняет
нелокальные запросы, а открытый HTTP не шифруется.
