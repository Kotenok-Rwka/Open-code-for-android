# PocketCode Desktop — установка (Windows / Linux)

Полноценный компаньон Android-приложения: чат с очередью, проекты и файлы, агенты, навыки, локальные модели, провайдеры, экономия токенов и двусторонняя синхронизация. Интерфейс в стиле «Аврора» с адаптивной боковой навигацией; создан по образцу Android-темы. Все тексты выводятся как текст, а не HTML, поэтому данные из чата не могут сломать страницу.

Для E2E-шифрования синхронизации ФК опционально использует пакет `cryptography` (в готовых пакетах он уже включён). Без пароля шифрование не требуется.

## Windows 10/11 (portable EXE)

1. Установи Python 3.10+ (https://python.org), если планируешь собирать самому.
2. Готовый вариант: распакуй `PocketCodeDesktop-<версия>-windows.zip`, запусти `PocketCodeDesktop.exe`.
3. Браузер откроется сам (http://127.0.0.1:8765/). Окно консоли не закрывай — это работающий компаньон. Если Windows SmartScreen ругается — «Подробнее → Выполнить в любом случае».
4. Сборка: `powershell -ExecutionPolicy Bypass -File build_windows.ps1`.

## Linux (Debian/Ubuntu, .deb)

```sh
sudo apt install ./pocketcode-desktop_<версия>_amd64.deb
pocketcode-desktop
# открой http://127.0.0.1:8765/
```

Или без пакета: `python3 pocketcode_desktop.py`.

## Автосинхронизация с телефона

1. На ПК запусти компаньон с `--host 0.0.0.0` (только в доверенной Wi-Fi сети).
2. На телефоне: меню «⋮» → «Автосинхронизация» → включи, укажи `http://<IP ПК>:8765`.
3. Выбери режим: «В реальном времени» (сообщения и правки файлов сразу), «По расписанию» (история + файлы каждые 5–60 мин) или «Оба».
4. Проверь вкладку «Автосинхронизация» в веб-интерфейсе — там виден статус и счётчик событий.

Формат пакетов описан в `sync_protocol.md` (v2). Секреты маскируются на телефоне до отправки.

## Ручной импорт/экспорт

- На ПК: вкладка «Обмен с телефоном» → экспорт JSON, либо `GET /api/sync/pack`.
- На телефоне: «Экспорт истории на ПК» / «Загрузить с ПК» в меню «⋮».
- Полный текст ответов доступен через `GET /api/messages/full`.

## IDE

См. `EDITOR_INTEGRATION.md`. Мост: `python3 ide_bridge.py`, порт 8766.

## Синхронизация через интернет (за 5 км, мобильный интернет)

1. На ПК запусти компаньон: `python3 pocketcode_desktop.py --host 0.0.0.0`.
2. Узнай токен: открой `http://127.0.0.1:8765/api/sync/token` на самом ПК.
3. Сделай ПК доступным извне, например Cloudflare Tunnel:
   ```sh
   cloudflared tunnel --url http://localhost:8765
   ```
   Он даст адрес вида `https://xxx.trycloudflare.com`.
4. На телефоне: «Автосинхронизация» → вставь этот HTTPS-адрес и токен, выключи «Только Wi-Fi», нажми «Проверить подключение».
5. Готово: синхронизация работает по мобильному интернету, адрес и токен сохраняются.

## Безопасность

Слушай только 127.0.0.1, если синхронизация не нужна. Для удалённого доступа обязательно используй HTTPS-туннель и токен: без токена компаньон отклоняет нелокальные запросы, а открытый HTTP не шифруется.
