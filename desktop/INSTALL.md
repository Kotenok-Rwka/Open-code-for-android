# PocketCode Desktop — установка (Windows / Linux)

Компаньон для телефона: чат с полными ответами без обрезки, автоматическая синхронизация, обмен задачами с IDE.

## Windows 10/11 (portable EXE)

1. Установи Python 3.10+ (https://python.org), если планируешь собирать самому.
2. Готовый вариант: распакуй `PocketCodeDesktop-windows.zip`, запусти `PocketCodeDesktop.exe`.
3. Открой http://127.0.0.1:8765/ в браузере.
4. Сборка: `powershell -ExecutionPolicy Bypass -File build_windows.ps1`.

## Linux (Debian/Ubuntu, .deb)

```sh
sudo apt install ./pocketcode-desktop_4.0.1_amd64.deb
pocketcode-desktop
# открой http://127.0.0.1:8765/
```

Или без пакета: `python3 pocketcode_desktop.py`.

## Автосинхронизация с телефона

1. На ПК запусти компаньон с `--host 0.0.0.0` (только в доверенной Wi-Fi сети).
2. На телефоне: меню «⋮» → «Автосинхронизация» → включи, укажи `http://<IP ПК>:8765`.
3. Выбери режим: «В реальном времени» (сообщения и правки файлов сразу), «По расписанию» (история + файлы каждые 5–60 мин) или «Оба».
4. Проверь вкладку «Автосинхронизация» в веб-интерфейсе — там виден статус и счётчик событий.

Формат пакетов описан в `sync_protocol.md` (v2). Секреты маскируются на телефоне до отправки.

## Ручной импорт/экспорт

- На ПК: вкладка «Обмен с телефоном» → экспорт JSON, либо `GET /api/sync/pack`.
- На телефоне: «Экспорт истории на ПК» / «Загрузить с ПК» в меню «⋮».
- Полный текст ответов доступен через `GET /api/messages/full`.

## IDE

См. `EDITOR_INTEGRATION.md`. Мост: `python3 ide_bridge.py`, порт 8766.

## Безопасность

Слушай только 127.0.0.1, если синхронизация не нужна. Для доступа с телефона используй `--host 0.0.0.0` только в доверенной сети — HTTP между приложениями не шифруется.
