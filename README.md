# PocketCode

**Кодинг-агент, который живёт в твоём телефоне.**
Пишешь задачу в чате, а агент сам читает и правит файлы, запускает команды, Python и git. ПК не нужен.

## Что это

PocketCode работает как OpenCode, Claude Code или Codex, только целиком на Android (Kotlin + Jetpack Compose). Подключаешь модель по API-ключу, открываешь проект и ставишь задачу. Агент читает код, правит файлы, запускает команды и тесты, делает коммиты. Работа идёт в фоне: можно свернуть приложение или выключить экран.

## Возможности

| | |
|---|---|
| **Агент** | Инструменты `read_file`, `edit_file`, `bash`, `python`, `git`, `grep`, веб-поиск, MCP, подагенты, режим плана, список задач, правила подтверждений |
| **Любая модель** | Anthropic, OpenAI-совместимые API (OpenAI, OpenRouter, Gemini, Groq, NVIDIA и свои адреса), шаблоны провайдеров, сравнение моделей |
| **Режим OpenCode** | Официальный клиент OpenCode внутри Linux на телефоне: беседы, несколько аккаунтов, лимиты и повторы, запасная модель, свой прокси |
| **Linux на телефоне** | Alpine в proot без root: `apk add python3 nodejs git`, проект виден как `/work` |
| **Проекты** | У каждого своя папка и история, несколько чатов во вкладках, снимки перед задачами, откат правок по блокам |
| **Видео**             | Режим «Видео» (Проект → Медиа): вырезать паузы, получить текст речи и вшить анимированные субтитры (7 стилей: классика, плашка, караоке, поп, громко, неон, комикс; .srt в комплекте), переходы между кусками (зум, наплыв, вспышка, сдвиг, размытие, круг, микс), монтаж по тексту (вычёркиваете слова, плеер сразу пропускает их), смотреть, сохранить в галерею или поделиться. Монтаж идёт через ffmpeg в Linux, речь распознаёт Whisper по API (подойдёт бесплатный Groq), агент умеет то же командами в чате |
| **Два телефона** | Синхронизация проектов и пульт: ставишь задачу на втором телефоне, выполняет первый (через приватный репозиторий GitHub, свой сервер не нужен) |
| **Удобство** | Нижняя панель (Чат · Проект · Агент · Ещё), тёмная тема, режим AMOLED, цвета на выбор, шаблоны запросов, отправка «позже», уведомления |
| **Безопасность** | Подтверждение опасных действий, защита приложения отпечатком или PIN, шифрованная копия настроек |
| **Управление телефоном** | Режим «Телефон» в чате: агент смотрит на экран, нажимает, листает, вводит текст и открывает приложения, в том числе на отдельном фоновом экране (с root или по беспроводной отладке). Основан на проекте [Mika](https://github.com/wangzan101/Mika), автор [wangzan101](https://github.com/wangzan101) |
| **Ассистент вместо Google** | PocketCode можно назначить цифровым помощником: долгое нажатие Home, жест или кнопка питания открывают окно. Спроси или скажи голосом (микрофон можно включать сразу при вызове), и ассистент найдёт в интернете и коротко ответит с источниками (или покажет список ссылок). Глубину ответа выбираешь сам: быстро, обычно или глубоко. После поиска окно предлагает показать ответ здесь или на весь экран; ход поиска видно в маленьком окне: от одного индикатора до подробных шагов. Раздел «О себе» помогает отвечать под тебя (город, интересы), а кнопка «Что на экране?» разбирает то, что было открыто в момент вызова. Команды «открой …», ссылки, калькулятор, время и дата, заметки («запомни …») выполняются на самом телефоне без нейросети, а команда для режима «Управление телефоном» передаётся прямо из окна ассистента. Ответ можно озвучить: выбираешь движок озвучки, а по желанию ставишь нейроголос (русские голоса Piper на sherpa-onnx, работают без интернета, скачиваются с Hugging Face). Закрытие готового ответа подтверждается, чтобы он не пропал случайно: первое касание вне окна или «Назад» спрашивает, второе закрывает (подтверждение можно выключить). История запросов хранится на телефоне, а пока окно закрыто, ход поиска виден плашкой поверх приложений или уведомлением |

## Установка

1. Открой [**Releases**](https://github.com/Kotenok-Rwka/Open-code-for-android/releases/latest) на телефоне и скачай `PocketCode.apk`.
2. Разреши установку из этого источника и поставь приложение.
3. **Ещё → Настройки**: выбери провайдера и вставь API-ключ.
4. Нажми на название проекта вверху, создай проект или открой папку телефона и напиши задачу, например: «найди, где обрабатывается вход, и добавь проверку пустого пароля».

Нужен Android 8.0 или новее. Обновления ставятся поверх без потери настроек.

> **Linux и OpenCode.** Alpine вшит в приложение: **Проекты → Установить Linux** распаковывает его без скачивания (если в сборке его нет, он скачается, ~4 МБ). Потом в **Терминале** кнопка «Установить OpenCode» поставит остальное сама.

## Как собрать самому

```bash
git clone https://github.com/Kotenok-Rwka/Open-code-for-android.git
cd Open-code-for-android
gradle :app:assembleDebug     # нужны JDK 17 и Android SDK
```

Или без ПК: **Actions → Build APK → Run workflow**, готовый APK появится в разделе Releases.

## Известные ограничения

- Проверено на реальных телефонах автора, но не на всех прошивках. Если proot не запускается, пришли отчёт из «Диагностики».
- Операторы связи в РФ могут обрывать трафик к Cloudflare (в том числе к `opencode.ai`): при ошибках `ECONNRESET` включи VPN и добавь в него PocketCode, либо укажи прокси в настройках OpenCode.
- Нет systemd и демонов, `pip` в встроенном Python недоступен (в Linux можно).
- Токены считаются приблизительно (~3 символа на токен).
- Доступ ко всем файлам телефона не пройдёт модерацию Google Play, поэтому приложение распространяется как APK.
- Бесплатные модели OpenCode имеют лимиты на стороне сервиса. Приложение их не обходит, а помогает пережить (повторы, запасная модель, второй аккаунт).

## Структура

```
app/src/main/java/com/pocketcode/
  llm/      клиенты Anthropic и OpenAI-совместимых API
  tools/    инструменты агента (файлы, bash, python, git)
  agent/    цикл агента, сжатие контекста, системный промпт
  linux/    Alpine + proot
  python/   Python в отдельном процессе
  session/  сессии и снимки проектов
  service/  фоновый сервис и уведомления
  ui/       чат, разделы, настройки, Markdown, темы
```

## Благодарности и лицензии

**Ассистент управления телефоном в PocketCode создан на основе проекта [Mika](https://github.com/wangzan101/Mika).**
Автор Mika: [wangzan101](https://github.com/wangzan101) (Copyright 2026 wangzan101). Mika распространяется по лицензии Apache-2.0.

Из Mika перенесены и изменены для PocketCode: схема «служба доступности + помощник с правами shell», встроенный клиент беспроводной отладки ADB,
передача Binder помощника, фоновый виртуальный экран, ввод через InputManager, защита от «всплытия» приложений на основной экран, автозапуск помощника после перезагрузки с автовключением беспроводной отладки,
установка барабанов выбора (время, дата) и распознавание текста с экрана (ML Kit: латиница и китайский).
В каждом перенесённом файле остаётся комментарий с указанием автора. Подробности: [THIRD_PARTY_MIKA.txt](THIRD_PARTY_MIKA.txt),
полный текст лицензии: [licenses/Mika-LICENSE-Apache-2.0.txt](licenses/Mika-LICENSE-Apache-2.0.txt).
Часть файлов помощника в свою очередь основана на [scrcpy](https://github.com/Genymobile/scrcpy) (Apache-2.0, Genymobile).
Локальные GGUF-модели запускаются через встроенный нативный llama.cpp: бинарник `llama-server` собирается workflow `.github/workflows/build-llama.yml` и кладётся в `assets/native/arm64-v8a/`. Приложение распаковывает его, копирует в Linux rootfs и поднимает OpenAI-совместимый сервер на `127.0.0.1:<порт>` (порт задаётся в «Локальных моделях», по умолчанию 8080) и сразу добавляет профиль подключения. Скачанные из каталога GGUF лежат в папке приложения `models` и подключены в Linux как `/root/.pocketcode/models`, поэтому сервер видит их без ручного копирования. На устройствах без arm64-бинарника остаётся подключение внешнего сервера LM Studio/Ollama.

Отдельные идеи (ветки беседы, каталог локальных моделей, контроль качества, импорт/экспорт чата, настройки размышлений) реализованы заново по мотивам проектов
[Agora](https://github.com/newo-ether/Agora) и [AndroidHarness](https://github.com/Sanuu7/AndroidHarness) (автор Sanuu7). Исходный код этих проектов не копировался. Подробности: [THIRD_PARTY_IDEAS.md](THIRD_PARTY_IDEAS.md).

Остальной код PocketCode распространяется по лицензии MIT, см. [LICENSE](LICENSE).
